# Gameplay design

1. Document the player fantasy and 15–60 second core loop.
2. Validate mechanics vs. luck, mastery, discoverability and choice.
3. Make difficulty progression based on demonstrated skill, not arbitrary spikes.
4. Separate success feedback, session rewards and long-term unlocks.
5. Introduce novelty using one mechanic at a time; keep a clear tutorial and failure recovery.
6. Create level fixtures and regression tests for solvability, fairness and pacing.
7. If children are the audience, avoid coercive retention and unbounded session pressure.
