# Game art pipeline

Keep production assets separate from concept art.

1. Define a single style bible with character silhouette, color palette, proportions, camera, lighting and finish.
2. Generate/render individual requested assets, not collage/screenshots. Characters must be exported with verifiable transparency; backgrounds should contain no baked controls or text.
3. Record source, licence, generation inputs, intended size and physical pixel dimensions.
4. Detect alpha halos, fake upscaling, wrong aspect ratio, compression, limb/identity drift and mismatch at real device scale.
5. Stage candidates apart from production assets; accept only after independent visual review.
6. Keep original editable format and export ready-to-use variants.
7. Build and compare **real game screenshots** against approved reference art before promoting.

Do not call a vector placeholder or a cropped design board 'professional 3D game art'.
