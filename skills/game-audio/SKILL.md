# Game audio

- Assign concise sonic cues to game states: tap, valid action, invalid action, combo, reward, pause and navigation.
- Avoid overlapping repeated effects or startling loudness; sidechain/duck where appropriate.
- Follow system silent mode and user controls on the target platform.
- Store source + licences; distinguish generated, recorded and placeholder audio.
- Verify mute, audio interruptions, background/resume and child-friendly volume.
