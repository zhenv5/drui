- Added `drui`, an original Skill usable by Codex, Claude Code, Antigravity and future supported agents.

- Added original design-direction, refresh/flow/feature, screenshot recreation, component, dashboard, mini-game scene, motion effects and 3D asset QA prompts.
- Added 19 original card pattern descriptions and a reference SwiftUI card gallery; **not** the 19 paid Pro templates.
- Added SwiftUI light-trail/dot-pattern/flow-gradient demo and 9/10 review rubric that requires real running UI evidence and task completion.
- Wired prompts into `game-ui-design`, `game-ux-flow`, `game-qa-review`, shared profiles, and universal review workflow.
- Updated upgrade process to carry `examples`, `references`, Quickstart and all nested prompts.
- Validation: standard-library installer tests, mac/iOS SwiftUI example syntax parse, Bash syntax, ZIP integrity. No claim of actual Xcode render or mobile UI pass.
