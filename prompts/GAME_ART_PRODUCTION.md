# Asset production prompt

Use `game-art-pipeline` and `game-ui-design`. Review approved character and scene references. Generate each asset independently (no UI collage). Define output size, alpha, palette, lighting, file format and integration placement. Stage results; check art source/licence, real pixel detail, matte edge, consistency, variant identities and actual rendered scale. Do not promote assets that look worse than existing production art. Run game and compare actual screenshots; mark unverified changes as candidates.
