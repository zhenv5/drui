# Extreme polish of one critical UI component

Pick a component with frequent user interaction (game number tile, answer chip, HUD meter, map node, menu CTA, inventory card or modal). Enumerate normal, hover if supported, pressed, drag-in/drag-out, selected, success, wrong, loading, disabled, focus, VoiceOver, dynamic text, narrow layout, Reduce Motion and destructive states. Define component anatomy, touch target, semantic tokens and predictable state machine. Produce a reusable implementation with clear dependency boundary and previews/fixtures. Test with real touch/mouse/keyboard events, verify no accidental double submission, then simplify visual noise. Include screenshots for at least 3 meaningful states and source diffs; never claim interaction works from still frames alone.
