# Choose the type of work before redesigning

Run one cold-start task and compare observed failures to the current user's request. Choose one mode and say why:

- **Refresh**: task is complete and correct, but hierarchy/material/brand coherence is weak. Keep screen architecture; improve design tokens, assets, consistency.
- **Flow fix**: user hesitates, loses state or cannot finish. Map user journey; fix navigation, feedback, copy, touch/keyboard, error recovery first.
- **New feature**: existing behavior works; specify user story, data/state, permission gates and success criteria. Build one thin vertical slice.
- **Component polish**: focus on a single critical component and all its states.
- **Mini-game scene**: map attention and input zones; optimize playfield and immediate feedback before decoration.

Deliver the selected mode, non-goals and exactly the user task used to verify improvements. Never silently change mathematical rules, progress or persistence as part of a visual refresh.
