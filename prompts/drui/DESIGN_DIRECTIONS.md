# Generate truly distinct game UI directions

For a new game/major redesign, synthesize 3 visual routes with distinct information architecture and memorable identity. Each must specify:
- audience, product category, 3 tone adjectives, one primary emotion, color-role tokens, type hierarchy and illustrative language;
- screen composition, focal point, art/interaction boundary, example high-interest moment, accessibility and localization tradeoffs;
- a sample main menu, one gameplay HUD and completion screen described in implementation-ready terms.

In a comparison table assess (1) legibility, (2) product fit, (3) implementation cost, (4) originality, (5) scalability and (6) likely task completion. Run an explicit **overlap audit**: if two concepts use the same hero, navigation, card pattern and emphasis with recoloring only, replace one. Pick a winner; preserve user-approved brand cues. Implement one real screen before multiplying the design across the project.
